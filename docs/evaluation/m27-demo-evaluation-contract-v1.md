# M27 primary demo and evaluation-lane decision

## Decision

M27 selects `A_EXISTING_SYNTHETIC_E2E` as the primary hackathon demo. It is the only
option that passes all seven frozen gates: a judge can understand it in 90 seconds, a
teammate can reproduce it from the public repository, it shows the complete
key→bag→sofa memory and query value, trace and uncertainty are visible, it requires no
excluded third-party bytes, it can be presented without an accuracy claim, and it stays
inside the five-person/three-day local prerecorded safety boundary.

M26 remains useful, but only as optional supporting evidence that one real reference
box enters the evaluator's small-object bucket. A two-frame positive/negative smoke is
not the product story and cannot measure a model gain. Starting a new model/data path
before the demo is ineligible because every delivery-bearing fact is still unknown.

## Option matrix

| Option | Pass | Fail | Unknown | Decision |
|---|---:|---:|---:|---|
| Existing project-owned end-to-end replay | 7 | 0 | 0 | Primary demo |
| M26 two-frame oracle | 3 | 4 | 0 | Optional mechanical smoke only |
| New model/data first | 0 | 0 | 7 | Deferred; separate scientific contract required |

The selected flow already has an exact six-step 90-second script, committed generated
media and manifests, wheel/clone resolution, a fixed question, an `estimated` scoped
answer, two evidence ranges, an abstention section, run receipt, warnings, and a red
`OPERATE DISABLED` boundary. That is stronger judge evidence than an unimplemented model
promise.

## Three evaluation lanes

1. **Public product demo — primary.** One committed project-owned clip demonstrates
   the end-to-end architecture and user value. It supports no real-home accuracy claim.
2. **Mechanical CV smoke — optional.** The public M26 receipt plus ignored local bytes
   exercise one M16 small-bbox target. It is neither required by the primary demo nor
   usable for gain, training, or tuning.
3. **Future scientific evaluation — deferred.** A separate contract must create
   protected-group development selection and an untouched frozen test. Model,
   threshold, tiling, and crop choices happen only on development; test runs once after
   selection. Paired quality/cost and group-aware uncertainty are required. Training
   remains capped at 20 epochs with patience 5.

A bootstrap interval over a single positive would be meaningless. Uncertainty becomes
decision-bearing only after multiple independent protected groups exist; adjacent
frames cannot be treated as independent samples.

## Hostile review

The synthetic demo can look toy-like, so it must be introduced as an architecture and
user-value prototype, with real CV receipts visibly separate. Perfect fixture metrics
must not lead the pitch and must retain the “not indoor evidence” warning. M26 stays a
receipt because its bytes are excluded and its sample is tiny. Prerecorded local-only
operation is presented as the reproducible B1 safety boundary, not as hidden live
capability. Finally, “Where is the key?” is a scoped state query, not proof of general
language understanding.

These dispositions make the bounded selection defensible; they do not resolve external
product validation, real-home transfer, or live-camera policy.

## Next authority

M28 may run only the committed project-owned synthetic demo and public tests against a
frozen 90-second acceptance checklist, then repair demonstrated presentation or script
gaps. It may not read third-party/private media, load another model, predict, train,
tune, emit new candidates/claims/relations, connect live/cloud/action capability, or
enable `OPERATE`.
