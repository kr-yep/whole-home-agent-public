# The camera's object detection, on a machine that will not install PyTorch.
#
# Ultralytics needs PyTorch, and PyTorch publishes exactly one macOS wheel per
# release: macosx_14_0_arm64. An Intel Mac has none, and neither does an Apple
# Silicon Mac on anything older than Sonoma, so pip falls back to a source build
# that does not finish. ONNX Runtime ships universal2 wheels reaching back to
# macOS 11, at about a sixth of the download.
#
#     pip install -r requirements-vision.txt
#     python tools/fetch_vision_model.py
#
# The weights are Ultralytics' own ONNX export of the same model, so this and the
# PyTorch path below detect the same things. Only the runtime differs.

onnxruntime>=1.19
numpy>=1.24
Pillow>=10.0.0
